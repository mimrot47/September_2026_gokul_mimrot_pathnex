## jenkins Pipeline - Maven build

you will learn how to compile, test, and package a java project using maven

pipeline { 
    agent any
    tool {
        maven 'Maven2-8-1'
        jdk 'JDK - 17'
    }
    stage('checkout') {
	steps {
		git url: 'mygiturl'
	}
    stage('Compile') {
	step { 
	    sh 'mvn clean compile'
	 }
    }
    stage('Test') {
	step {
	    sh 'mvn test'
         }
    }
    stage('Package') {
	 steps {
		sh 'mvn package'
	    }
        }
